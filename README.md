## ✨ Features

- Explore an interactive world map with saved city markers.
- Add and delete cities with visit dates and personal notes.
- Automatically retrieve city and country information from selected map coordinates.
- Browse visited cities and countries.
- Navigate through protected application pages.

## 🛠️ Built With

- React 18
- JavaScript (ES6+)
- React Router DOM
- Context API and `useReducer`
- Custom Hooks
- React Leaflet
- JSON Server
- CSS Modules

## 💡 What I Learned

This project helped me improve my understanding of **React Router**, especially nested routes, dynamic route parameters, protected routes, and navigation between different parts of an application.

I also learned more about **code splitting with `React.lazy` and `Suspense`**, allowing route-level components to load when needed instead of loading everything upfront.

Another important step was gaining more practical experience with the **Context Provider pattern** for sharing state across components, together with `useReducer` for managing more structured state transitions.

I also practiced building **custom hooks** to encapsulate reusable logic, including browser geolocation and reading coordinates from URL search parameters.

These concepts gave me a stronger foundation in structuring React applications. I plan to explore the Context Provider pattern and custom hooks in greater depth in my upcoming projects.
